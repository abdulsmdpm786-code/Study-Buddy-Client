# 🎓 Study Buddy - The All-in-One Student Dashboard

This is the frontend client for the **Study Buddy** application. Built with a focus on user experience, this platform serves as the ultimate, all-in-all hub for students. It features a beautifully clean, animated user interface and a suite of powerful tools designed to make learning engaging and organized.

🌍 **Live Demo:** [Study Buddy App](https://study-buddy-client-red.vercel.app/)

---

## 🛠️ Tech Stack

* **Frontend Framework:** React (via Vite)
* **Styling & UI:** Tailwind CSS (for a highly responsive, modern, and animated design)
* **Routing:** React Router DOM (with secure Protected Routes)
* **API Client:** Axios (configured for secure cross-domain authentication)
* **Backend Integration:** Built to connect seamlessly with a Node.js/Express & MongoDB backend.
* **Deployment:** Vercel

---

## ✨ Key Features

* **🎨 Clean & Animated UI:** A visually engaging and intuitive dashboard styled entirely with Tailwind CSS, featuring smooth animations for a premium, frictionless user experience.
* **📚 Course & Quiz Hub:** Students can seamlessly explore educational content, attend interactive quizzes, and track their academic progress over time.
* **✍️ Student Blogging Platform:** A built-in space for users to create, publish, and read blogs, fostering a community of shared knowledge.
* **🤖 AI-Powered Assistance:** Dedicated sections for students to explore and leverage innovative AI features to enhance their learning and productivity.
* **✅ Smart Task Management:** A comprehensive To-Do list feature allowing students to assign, organize, and check off their daily academic tasks.
* **📖 Integrated Dictionary & Focus Tools:** Features a quick-lookup dictionary for students to instantly find the meaning of words, alongside a built-in study timer to maintain focus without leaving the dashboard.
* **🔒 Secure Authentication:** Utilizes HTTP-only cookies for JWT-based login, ensuring high security across different domains (Vercel to Render).
